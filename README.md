# מחשבון דיגיטלי באמצעות ארדואינו

## על הפרויקט

בפרויקט זה בניתי מחשבון דיגיטלי המבוסס על לוח ארדואינו אונו. מטרת הפרויקט היא ליצור מחשבון שמאפשר למשתמש לבצע פעולות חשבון באמצעות מקלדת פיזית ולהציג את התרגיל ואת התוצאה על גבי מסך.

במהלך העבודה חיברתי בין הרכיבים, כתבתי את הקוד להפעלת המחשבון ובדקתי את פעולתו.

## הרכיבים בפרויקט

במחשבון השתמשתי בלוח ארדואינו אונו, במקלדת מטריצה הכוללת 16 מקשים, במסך בגודל 16 על 2 עם מתאם תקשורת, בחוטי חיבור ובתושבת שעליה הורכבו הרכיבים.

לכל רכיב יש תפקיד במערכת: המקלדת משמשת להזנת המספרים ולבחירת פעולת החשבון, הארדואינו מעבד את הנתונים ומבצע את החישוב, והמסך מציג את התרגיל, את התוצאה ואת הודעות השגיאה.

## איך המחשבון עובד?

בתחילת השימוש אפשר לאפס את המחשבון באמצעות מקש הכוכבית. לאחר מכן מקלידים את המספר הראשון, בוחרים את פעולת החשבון ומקלידים את המספר השני. לחיצה על מקש הסולמית מבצעת את החישוב ומציגה את התוצאה על המסך.

המחשבון תומך בארבע פעולות חשבון:
- חיבור
- חיסור
- כפל
- חילוק

בנוסף, התוכנית כוללת בדיקות שמטרתן לזהות מצבים שבהם אי אפשר לבצע את החישוב, כמו חילוק באפס או חריגה מהגבול המספרי שנבדק בקוד.

## תפקידי המקשים

- **A** – חילוק.
- **B** – כפל.
- **C** – חיסור.
- **D** – חיבור.
- **#** – חישוב התוצאה.
- **\*** – איפוס המחשבון.

## הקוד והתוכנה

הקוד נכתב עבור לוח ארדואינו אונו ומשתמש בשתי ספריות: אחת לקליטת הלחיצות מהמקלדת ואחת לשליטה במסך. בעזרת הקוד הארדואינו מזהה את המקשים שנלחצים, שומר את המספרים שהוקלדו, מבצע את פעולת החשבון המתאימה ומציג את התוצאה.

הקוד המלא של הפרויקט נמצא בקובץ `calculator.ino` שבמאגר זה.
